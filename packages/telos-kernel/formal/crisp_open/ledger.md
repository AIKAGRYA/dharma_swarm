# Adversarial Iteration Ledger

**Ledger rule:** append-only. Each completed iteration records the constructor delta, the mechanical verifier result, all six adversarial surfaces, limb status, and the referee ruling.

**Role-separation disclosure:** the available execution surface did not expose a subagent-spawning primitive. CONSTRUCTOR, ADVERSARY, and REFEREE were therefore run as sequentially isolated passes with non-overlapping authority in each iteration; they are not claimed to be externally independent agents. VERIFIER is mechanically separate: GitHub Actions plus Lean/leanchecker, and it reports without repairing or interpreting. Automated repository reviewers, when present, remain additional untrusted adversaries rather than acceptance authority.
