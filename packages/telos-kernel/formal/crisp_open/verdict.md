## Result

The original synthesis has been converted from a vague question into a precise open/closed fork with machine-checked structural results.

1. A restricted proof-carrying self-modification model can preserve a nonvacuous semantic invariant through arbitrarily many accepted rewrites while its modification operator is itself mutable and the checker remains fixed outside state.
2. The withdrawn range-based anti-generator condition is degenerate for effectively checkable finite-path reachability: one fixed certificate-replay interpreter covers every reachable state when its input may contain the path.
3. For every explicit object-language minimum-description model equipped with a fixed closed composer, a closed deterministic lineage satisfies

   `K(sₙ) ≤ K(s₀) + K(step) + K(n) + O(1)`.

4. The checked natural-number code has length

   `bitLength(n) + 2 · bitLength(bitLength(n)) + 1`,

   giving the intended `log n + 2 log log n + O(1)` shape.
5. A pure counter pays the same depth-description term. Descriptive complexity at the closed ceiling therefore does not distinguish qualitative novelty from counting.
6. Opening the system replaces the depth-only explanation with explicit information accounting:

   `K(s) ≤ K(seed) + K(step) + K(consumed input) + O(1)`.

7. Invariant preservation and information arrival are separate obligations. A fixed checker constrains how supplied information may be transformed; it does not determine whether information enters the lineage.

## Model reservation — Surface 8

The Iteration 5 model formally defeats the declared product-decomposition attack, but its coupling is not load-bearing. The reachable constant-description rewrite `.wrapDouble` increases the chosen semantic magnitude forever while preserving parity. An unsafe successor operator would increase the same coordinate and violate the invariant, and the fixed checker rejects its installation, but safe growth still requires no increasing preservation effort.

Therefore the model is accepted as a correct restricted closure/self-modification construction, not as a model of qualitative open-ended evolution.

## Why this is crisp-open rather than solved

The descriptive branch is now precise: closed deterministic systems have only the seed, fixed step, and depth description available; faster descriptive growth requires accounted external information. The structural branch remains open: no accepted formal measure is supplied here for new organizational levels, observables outside the seed ontology, or unbounded growth in the minimum ontology required to describe behavior.

The development thus identifies where the real unresolved question lives instead of promoting a gameable scalar theorem into a solution.
