## Receipt Protocol

Mark claims as:

- `SUPPORTED`: test or receipt exists and matches the claim.
- `PARTIAL`: prose/design exists but no mechanical graph or runtime path exists.
- `UNBUILT`: named but not implemented.
- `BLOCKED`: depends on consent, live registration, external account action, or a missing substrate gate.

Do not create `reports/telos_ai/FIRST_EXTERNAL_ACTED_RECEIPT.md` until an
external human has actually acted. A receipt format or template is not a
receipt.
