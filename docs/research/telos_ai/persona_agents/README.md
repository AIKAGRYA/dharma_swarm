# TELOS Morning Refinery Persona Agents

These prompt files seed the canonical specialist lenses for the
`ARTICULATE_ESSENCE_EXTRACTOR_NODE` council.

Use them as developer/system prompts for independent first-pass readings of one
raw or typo-clean morning page. The agents should not see each other's outputs
until after their first pass is complete.

This is the first-stage noetic/essence council. The second-stage empire and
idea-portfolio agents live in `../empire_agents/` and must not run until this
council has stabilized a source-faithful node.

## Shared Protocol

Read `00_RESEARCH_BASIS_AND_COUNCIL_PROTOCOL.md` before changing the set.

The council exists to create a richer, source-faithful semantic node from a raw
morning page. It should deepen articulation, not flatter the user. It should
cross-pollinate real disciplines, not decorate the output with names. It should
make the source more intelligible while preserving uncertainty, privacy, and the
user's authority to correct the node.

Minimal run shape:

1. Store raw source privately.
2. Create typo-clean working transcript.
3. Run six independent persona passes.
4. Synthesize into an `ARTICULATE_ESSENCE_EXTRACTOR_NODE`.
5. Run contradiction/anti-inflation pass.
6. Ask the user to correct the node.
