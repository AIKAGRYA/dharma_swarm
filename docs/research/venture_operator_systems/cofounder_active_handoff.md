## Darshan Owns

- final claims;
- final editorial voice;
- source-trust decisions;
- correction/refusal decisions;
- sacred/name/positioning judgment;

- decision deltas.

## Distribution Machine

Each strong canonical artifact should become:

```text
canonical Darshan artifact
-> source pack / claim ledger / attention ledger
-> newsletter version
-> X thread and hooks
-> LinkedIn operator version
-> Instagram carousel
-> Medium/Ghost/Substack variants
-> short video scripts
-> quote cards
-> spin-off mini essays
-> direct outreach
-> reader feedback
-> paid membership / donation / pre-order / advisory leads
-> analytics
-> next artifact decision
```

Use AI heavily for:

- versioning;
- hooks;
- repurposing;
- calendar management;
- analytics synthesis;
- outreach drafting;
- monetization experiments;
- audience-specific adaptations.

Every derivative must trace back to the canonical artifact and claim ledger. No platform version may exaggerate claims for performance. No bots, fake personas, astroturfing, spam, or deceptive engagement.

## Season 0 Success

Minimum credible proof:

- 3-5 excellent canonical artifacts live;
- 100-500 real readers reached;
- 25+ thoughtful replies or survey responses;
- 25+ early list joins;
- 5-10 willingness-to-pay signals;
- 1+ institutional/advisory lead;
- 1+ artifact earns unsolicited external sharing;
- repeatable distribution/revenue runbook exists and has been tested.

Stretch:

- 100+ paid subscribers; or
- one artifact circulates meaningfully beyond the founder network.

## Cofounder Operating Rule

Maximize propagation and monetization while Darshan/Dharma Swarm protects the seeing, evidence, source trust, and final voice.
