## Cofounder: Current Best Fit

Why Cofounder fits Darshan Season 0:

- Cofounder pricing page advertises human approval flow, agent inboxes, managed services, brand creation, CRM/outreach setup, content/campaign assets, social integrations, and project ownership graduation.
- Cofounder docs expose workspace tasks with Needs Action, Ongoing, Done, and Todo states.
- Cofounder custom agents route repeatable work to agents with clear specialty, tools, approvals, and output formats.
- Cofounder skills are reusable guidance packages attachable to agents.
- Cofounder marketing agent owns campaigns, positioning, creative assets, launches, channel plans, calendars, content systems, marketing-site work, and measurement plans.
- Cofounder sales agent owns ICP, outbound, customer development, pipeline, follow-up, consult calls, pitches, negotiation, and account handoff, with review before external actions.
- Cofounder design agent owns brand systems, visual assets, decks, email templates, UI kits, and design-token recommendations.
- Cofounder publishing works through GitHub PRs from `main` to `prod` and Vercel deployment after merge.
- Cofounder MCP support lets connected apps become available to agents through Composio-powered MCP integrations.

Darshan implication:

Cofounder can operate the shell around the artifact loop. It should not become the authorizing layer for the artifact itself.

## Polsia: Current Best Benchmark

Why Polsia remains important:

- It represents the strongest public category claim: one founder plus AI agents can run a company.
- It is closer to the eventual Dharma Swarm ambition of many VentureCells operated through one interface.
- Its reported revenue-share/pricing and autonomy posture are useful warnings for Dharma Swarm's trust and capture gates.

Darshan implication:

Do not give Polsia the Darshan shell yet. Use it later as a benchmark for company-running autonomy, customer-revenue attribution, and agent orchestration gaps.

## What Not To Copy

- autonomous outreach without review;
- opaque claims about agent success;
- fake social proof;
- revenue-share capture that compromises editorial judgment;
- publishing without claim-ledger traceability;
- design polish that hides lack of artifact proof;
- bot-swarm distribution that violates Darshan's attention ethic.
