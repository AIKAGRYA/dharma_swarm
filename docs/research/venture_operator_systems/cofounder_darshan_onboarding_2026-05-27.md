## Design Implications For Dharma Swarm

1. Cofounder-style onboarding is a useful primitive: ask targeted venture questions, lock business plan, then scaffold workstreams.
2. Dharma Swarm's native VentureCell operator should include a similar first-run wizard.
3. The wizard must include Dharma Swarm-only gates:
   - beneficiary;
   - value proposition;
   - first proof;
   - kill condition;
   - allowed autonomy;
   - forbidden scope;
   - source of truth;
   - decision-delta requirement.
4. Brand/design should not precede artifact proof unless the cell's artifact loop already exists.
5. External operator outputs must be logged as field observations, not trusted as source-of-truth state.
