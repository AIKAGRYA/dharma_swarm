# CVE-2026-25253 — OpenClaw 1-click RCE

**Source:** https://nvd.nist.gov/vuln/detail/CVE-2026-25253
**Publish date:** February 1, 2026
**Status:** Awaiting NVD analysis (MITRE-assigned CVSS)

## Description (verbatim from NVD)
"OpenClaw (aka clawdbot or Moltbot) before 2026.1.29 obtains a gatewayUrl value from a query string and automatically makes a WebSocket connection without prompting, sending a token value."

## CVSS
- **Base score:** 8.8 (HIGH)
- **Vector:** `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`
  - AV:N — network attack vector
  - AC:L — low attack complexity
  - PR:N — no privileges required by attacker
  - UI:R — user interaction REQUIRED (1 click)
  - S:U — scope unchanged
  - C:H / I:H / A:H — confidentiality, integrity, availability ALL high impact

## CWE
- **CWE-669** — Incorrect Resource Transfer Between Spheres

## Affected versions
OpenClaw (formerly clawdbot / Moltbot) for Node.js, all versions before **2026.1.29**

## The chain (synthesized from advisories)
1. Victim clicks a crafted URL while OpenClaw is running locally
2. OpenClaw reads `gatewayUrl` from query string
3. OpenClaw automatically opens a WebSocket to attacker-controlled gatewayUrl **without confirmation prompt**
4. OpenClaw sends the user's auth token over that WebSocket
5. Attacker has token → impersonates user to OpenClaw gateway → can register tools, push instructions, achieve RCE in the OpenClaw process
6. From there: arbitrary shell access, exfiltrate API keys for Claude/OpenAI/Google AI/etc. stored locally

## Fix
v2026.1.29 added a **confirmation prompt** when gatewayUrl changes. Note: this is mitigation, not elimination — phishing the prompt is still possible.

## Real-world exposure
SocRadar / Hunt.io / others reported **~17,500 exposed OpenClaw/clawdbot/Moltbot instances** internet-facing at the time of disclosure.
