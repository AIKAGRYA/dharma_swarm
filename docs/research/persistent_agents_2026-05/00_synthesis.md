## Keystone

The single most important pattern to port is keypair identity bound to an append-only participant event/memory log.

Without that, dharma_swarm has many useful traces but no hard answer to "same agent, same memory, same authority?" across restarts, host moves, or model swaps.

## Five next moves

1. Add keypair-per-participant identity and participant manifests for PersistentAgent conductors and witnesses.
2. Bind AgentMemoryBank, witness writes, registry identity, tool policy, and wake schedule to that manifest.
3. Add signed SAB contribution and signed operator-attestation records.
4. Create narrow SAB adapters first for Hermes Agent, Letta, OpenClaw, and ElizaOS; treat AI Garden as a scheduled-world-state integration.
5. Run a 30-day operator-distance trial with daily scorecard rows, action logs, memory snapshots, and external-auditor-readable artifacts.
