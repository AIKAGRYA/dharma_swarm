CrewAI memory - evidence excerpt

Memory enablement

from crewai import Agent

analyst = Agent(
    role="Data Analyst",
    goal="Analyze and remember complex data patterns",
    memory=True,
    verbose=True,
)

Context7 source summary: CrewAI agents can enable memory with memory=True to maintain context across multiple interactions and improve handling of complex multi-step tasks.

Crew memory

crew = Crew(
    agents=[researcher, writer],
    tasks=[research_task, writing_task],
    process=Process.sequential,
    memory=True,
    verbose=True,
)

Context7 source summary: CrewAI crews can use default memory or custom Memory instances. The crew extracts facts from task outputs and injects relevant context into prompts.

Memory types and scoring

Context7 source summary: CrewAI docs describe short-term memory for recent context, long-term memory for persistent patterns across sessions, entity memory for people/places/concepts, and contextual memory for continuity. The newer unified Memory API supports semantic similarity, recency, and importance scoring with configurable weights.

Survey interpretation

CrewAI is not scored as a SAB participant because it is a framework. The pattern worth porting is a single agent-facing memory API over multiple memory types with scored recall.
