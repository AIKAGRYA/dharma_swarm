## The Arjuna Test

Before any new build, hook, skill, plan, doc, or agent: **"Does this point a weapon at something broken in the world?"**

- Yes → ship it.
- No → it doesn't get built.
- Maybe → name the external user / dataset / partner / measurable impact within 90 days, or it doesn't get built.

Red flags that should stop work immediately:
- "Let's design an experiment to test whether dharma_swarm itself..."
- "What if we made [internal thing] more recursive / Hofstadterian / fractal..."
- "This skill could generate skills about itself..."
- "Beautiful recursive structure" / "elegant self-reference" / "lattice density"
- Any frame that aims new tools INWARD when they were imported to aim outward
