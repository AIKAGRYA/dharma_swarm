# Six-Agent Build Receipt

Date: 2026-06-25

This suite was populated from six parallel specialist packets, then integrated
into a single operator-ready prompt-test pack.

## Agent Packets

1. Testing and verification: collection reality, changed-surface mapping,
   Hypothesis strength, replay determinism, governance wiring, state isolation,
   assertion strength, mock realism, complexity budget, and AI-slop evidence.
2. Architecture and complexity: module depth, fan-in/fan-out, cycles, boot
   order, seams, source-of-truth duplication, blast radius, runtime surface
   wiring, persistence coupling, and reduction planning.
3. Runtime and distributed reliability: dispatch receipts, idempotency, A2A/NATS
   lifecycle, runtime state, replay, provider fallback, observability, chaos,
   board consistency, and runtime-truth falsification.
4. AI slop and prompt security: claim falsification, verification evidence,
   instruction boundaries, memory poisoning, slopsquatting, ghost APIs,
   generated residue, unsafe autonomy, secrets, and gate gaming.
5. Governance, evidence, and fitness: fitness functions, ratchets, baselines,
   evidence grading, claim/evidence binding, active-track truth, conformance
   tests, hygiene lifecycle, authority boundaries, and weekly governance.
6. Operator synthesis: schema, evidence levels, weekly cadence, issue/PR mode,
   anti-hallucination rules, and council synthesis.

## Integration Decision

The prompts are stored as five council packs with ten prompt sections each,
rather than 50 loose files. This keeps the suite navigable while preserving all
50 distinct expert prompt instruments and five separate synthesis prompts.

## Evidence Contract

Every prompt requires concrete repo evidence, command reporting, and explicit
`not_proven` handling. Prompt output remains advisory until converted into an
executable test, gate, issue, or implementation task.
