# Council 04: AI Slop and Prompt Security Prompts

Council ID: `ai_slop_prompt_security`

Use these prompts to prevent hallucinated capability claims, prompt injection,
memory poisoning, slopsquatting, generated-code residue, unsafe autonomy,
secret leakage, and visible-gate gaming.

## Shared Prompt Contract

```text
Audit only. Do not edit files.

Treat model self-report, docs, PR text, generated reports, and old receipts as
claims, not evidence. Every output must include commands_run,
claim_evidence_table, findings, NOT_PROVEN, and failure_classes.
```

## Prompt APS-01: Claim Falsifier

Expert lens: skeptical release auditor.

Mandatory commands:

```bash
rg -n "(?i)(production-ready|verified|works|complete|live|integrated|all checks pass|100%|world-class|real)" README.md docs reports .github scripts dharma_swarm
git log -n 20 --oneline
```

Failure classes:

- `HALLUCINATED_CAPABILITY`
- `DOC_RUNTIME_DRIFT`
- `STALE_RECEIPT`
- `CLAIM_SCOPE_CREEP`

Required output: claim/evidence table with each claim marked proven, partial, or
not proven.

## Prompt APS-02: Verification Evidence Gate

Expert lens: forensic CI and receipt reviewer.

Mandatory commands:

```bash
rg -n "(?i)(tests passed|verified|green|works|all checks pass)" docs reports .github scripts --glob "*.md" --glob "*.json" --glob "*.yml" | rg -v "(exit|command|receipt|artifact|sha|run|http|https)"
make hygiene-audit
```

Failure classes:

- `EVIDENCE_FREE_VERIFICATION`
- `SELF_REPORTED_GREEN`
- `MISSING_EXIT_CODE`
- `UNREPLAYABLE_PROOF`

Required output: every unsupported verification claim and the command that would
prove or disprove it.

## Prompt APS-03: Trusted Instruction Boundary

Expert lens: LLM application security auditor.

Mandatory commands:

```bash
rg -n --glob "!AGENTS.md" --glob "!CLAUDE.md" --glob "!docs/governance/hygiene/**" "(?i)(ignore (all )?(previous|above) instructions|system prompt|developer message|you are now|act as|must obey|do not tell the user)" .
rg -n "prompt|message|query|input|instruction" dharma_swarm api scripts
```

Failure classes:

- `PROMPT_INJECTION_SURFACE`
- `UNTRUSTED_TEXT_AS_AUTHORITY`
- `MISSING_DELIMITER`
- `INSTRUCTION_FILE_BLOAT`

Required output: trusted instruction boundary map and unsafe untrusted-text flow.

## Prompt APS-04: Memory and Context Poisoning

Expert lens: durable-memory integrity auditor.

Mandatory commands:

```bash
git diff --name-only origin/main...HEAD | rg "(^docs/agents/|^docs/onboarding/|^reports/.*/memory|^\\.agents/|memory|context|AGENTS|CLAUDE)"
rg -n "(?i)(remember|memory|context|must obey|always|operator said|verified)" .agents docs reports dharma_swarm
```

Failure classes:

- `MEMORY_POISONING`
- `UNVERIFIED_DURABLE_CLAIM`
- `CONTEXT_AUTHORITY_CONFUSION`
- `GENERATED_CONTEXT_LEAK`

Required output: durable context additions and their evidence chain.

## Prompt APS-05: Slopsquatting and Phantom Dependency Audit

Expert lens: supply-chain security reviewer.

Mandatory commands:

```bash
git diff --name-only origin/main...HEAD | rg "(^pyproject\\.toml$|requirements.*\\.txt$|package\\.json$|uv\\.lock$|go\\.mod$|Cargo\\.toml$|pnpm-lock\\.yaml$|package-lock\\.json$)"
```

For each new dependency, run registry proof such as:

```bash
python -m pip index versions <pkg>
npm view <pkg>
go list -m -versions <module>
```

Failure classes:

- `SLOPSQUATTING_RISK`
- `PHANTOM_PACKAGE`
- `UNPROVEN_PUBLISHER`
- `DEPENDENCY_NOT_NECESSARY`

Required output: dependency provenance table.

## Prompt APS-06: Dependency Provenance and Ghost API Audit

Expert lens: API compatibility auditor.

Mandatory commands:

```bash
rg -n "openai[.]ChatCompletion|openai[.]Engine|text-davinci|[.]query[(]" dharma_swarm api scripts
python -m pip show <pkg>
```

Run package metadata checks for changed dependencies.

Failure classes:

- `GHOST_API`
- `REMOVED_API_CALL`
- `CROSS_ECOSYSTEM_NAME_BORROWING`
- `LOCKFILE_SOURCE_MISMATCH`

Required output: API call provenance table and any doc/version mismatch.

## Prompt APS-07: Generated Code Residue Audit

Expert lens: generated-code maintainability auditor.

Mandatory commands:

```bash
rg -n "(?i)(generated by|as an ai|chatgpt|copilot|placeholder|stub|todo|not implemented|magic|obviously)" dharma_swarm api scripts tests docs
rg -n "except Exception|assert True|assert .*is not None|pass\\s*(#.*)?$" dharma_swarm api scripts tests
```

Failure classes:

- `GENERATED_RESIDUE`
- `PLACEHOLDER_SHIPPED`
- `BROAD_EXCEPTION_MASKING`
- `TRIVIAL_TEST_THEATER`

Required output: ranked residue list with deletion, test, or ownership action.

Expert lens: autonomous-agent safety and side-effect auditor.

Mandatory commands:

```bash

rg -n "(objective|non-goals|allowed touch|blast radius|rollback|no-change|admission)" docs reports .agents
```

Failure classes:

- `UNADMITTED_AUTONOMY`
- `OVERBROAD_SIDE_EFFECTS`
- `NO_ROLLBACK_PATH`
- `SHELL_ESCALATION_RISK`

Required output: autonomy side-effect map and missing admission contracts.

## Prompt APS-09: Secrets and Log Leakage Audit

Expert lens: secrets handling and observability auditor.

Mandatory commands:

```bash
rg -n "(?i)(api[_-]?key|secret|token|password|bearer|authorization|DATABASE_URL|OPENAI|ANTHROPIC|GITHUB|NATS)" . --glob "!*.lock"
rg -n "(print|logger|logging).*?(env|token|secret|headers|payload|authorization)" dharma_swarm scripts api
```

Failure classes:

- `SECRET_IN_REPO`
- `SECRET_IN_LOG`
- `UNREDACTED_PAYLOAD`
- `CREDENTIAL_PROVENANCE_LEAK`

Required output: potential secret table, redaction evidence, and false-positive
notes.

## Prompt APS-10: Anti-Gaming Gate Integrity Audit

Expert lens: adversarial evaluator and CI-gaming auditor.

Mandatory commands:

```bash
git diff --name-only origin/main...HEAD | rg "(^tests/|^\\.github/workflows/|^scripts/governance/)"
rg -n "(skip|xfail|pragma: no cover|assert True|mock|monkeypatch|negative control|holdout|mutation)" tests .github scripts docs reports
```

Failure classes:

- `VISIBLE_GATE_GAMING`
- `TEST_WEAKENING`
- `NO_NEGATIVE_CONTROL`
- `CONSENSUS_WITHOUT_INDEPENDENT_EVIDENCE`

Required output: gate-gaming risk table and one holdout or mutation check.
