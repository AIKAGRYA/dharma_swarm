# Weekly Rotation

The full suite has 50 prompts. Run all 50 before releases. For ordinary weeks,
rotate the deep load while still running a small sentinel set.

## Sentinel Set Every Week

Run these every week:

- `TV-01 Pytest Collection Reality Audit`
- `TV-02 Changed-Surface Test Mapping Audit`
- `AC-02 Fan-In/Fan-Out Hub Pressure Audit`
- `RDR-01 Dispatch Receipt Completeness Audit`
- `APS-01 Claim Falsifier`
- `APS-02 Verification Evidence Gate`
- `GEF-02 Governance Ratchet and Regression Gate Audit`
- `GEF-06 Active-Track Truth and Portfolio Graph Audit`

## Four-Week Rotation

Week A:

- all council 01 prompts;
- council 04 prompts 01, 02, 07, 10.

Week B:

- all council 02 prompts;
- council 05 prompts 01, 02, 03, 09.

Week C:

- all council 03 prompts;
- council 01 prompts 03, 04, 06, 08.

Week D:

- all council 04 and 05 prompts.

## Release Week

Run all 50 prompts, then run all five council synthesis prompts.

The release-week output must include at least one concrete proposed test or gate
for every high-severity finding.
