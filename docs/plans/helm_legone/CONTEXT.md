# Helm product language

Document role: reference. Scope: Helm product terminology. Subordinate to the
[Wayfinder convergence plan](HELM_WAYFINDER_E2E_PROTOTYPE_PLAN_20260901.md) and
[leg-one destination](HELM_LEGONE_SPEC.md); replaces no runtime or authority contract.

## Language

**Helm**:
The operator's persistent seat for conversation, inspection, and permitted control
of Dharma Swarm.
_Avoid_: a separate desktop brain, a second swarm.

**Desktop extension**:
The proposed collection of Mac workspaces, shortcuts, and indicators through which
the operator reaches the same Helm seat and work.
_Avoid_: a new operating system, an independent control center.

**Operator seat**:
The continuity of the operator's current conversation, selected work, and evidence
across changes of view.
_Avoid_: a particular terminal window, a particular model.

**Workspace profile**:
A named arrangement of project resources and preferred views for an activity such
as research or implementation. It expresses a preference, not permission to execute
work on those resources.
_Avoid_: mission, execution grant.

**Curator seat**:
An agent seat whose context contains the relevant, attributed material for its
current task while retaining access to deeper sources.
_Avoid_: whole-estate prompt, accumulated transcript as knowledge.

**Effect hand**:
The proposed path from an operator's requested action to execution by its authorized
owner. A suggested action and an executed action remain distinct.
_Avoid_: shell access implied by conversation, model confidence as permission.
