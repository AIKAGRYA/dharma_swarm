# Outreach message template

Short, specific, receipt-led. Never mass-send; personalize the bracketed
fields. The point is to subtract from the recipient's uncertainty, not add to
their inbox. Operator sends by hand after approving the list.

---

Subject: An independent check on whether [their agent] does what it claims

Hi [name],

We publish independent, reproducible verifications of AI agents — the outside
witness, with the misses shown. Recent public dissection of the field's most
famous *unverified* speedups: [link to the anatomy article].

For [their agent / product], we'd run a fixed-scope check: does it hold up under
adversarial pressure and on scenarios it never saw? You get a sealed receipt you
can re-run yourself, plus a one-page report card with a published-misses
appendix. Fixed fee ~$2,500; a continuous re-verification retainer if useful.

If a verified "it does what it claims" (or an honest "here's where it doesn't")
would be worth $2,500 to you before [their next release / a customer commitment],
I'll send a one-page scope. If not, no worries — the anatomy piece above stands
on its own.

[your name]

---

Guardrails: one message per prospect; lead with the public artifact; state the
price; make the "no" easy; never attach or imply a security-vulnerability
finding; never claim a result the receipt has not passed to ring 3.
