- Use them to orient, not to guess implementation seams.
- After reading them, open the exact code files for the domain you are touching.

## Why This Exists

The repo has many specs, maps, and historical docs. This hub keeps the active governance layer in one easy-to-find place without breaking root-level tool compatibility for `CLAUDE.md`.
