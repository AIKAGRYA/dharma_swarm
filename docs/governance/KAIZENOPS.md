# KaizenOps v0

KaizenOps is the learning layer above AgentOps.

AgentOps is single-run discipline: a bounded work packet, isolated worktree,
allowed-file scope, declared gates, structured report, and no automatic merge or
push.

KaizenOps is multi-run learning: it reads completed AgentOps reports and asks
what should improve in the next packet, playbook, gate, or human decision.

## KaizenReview

KaizenReview v0 is generated by:

```bash
python scripts/governance/kaizen_review_from_agentops.py \
  --input reports/agentops \
  --output reports/kaizen/latest
```

It writes:

```text
reports/kaizen/latest/kaizen_review.json
reports/kaizen/latest/kaizen_review.md
```

The review summarizes:

- gate outcomes
- scope violations
- commit and approval outcomes
- waste patterns
- stop-doing candidates
- playbook update candidates
- exactly one next work-packet recommendation

## Governance Boundary

KaizenReview reads AgentOps evidence and writes review artifacts. It is not a
daemon, dashboard, API, live swarm, merge bot, memory system, ontology system, or
Daily Operating Brief implementation.

AI may suggest process improvements, but human approval is required before:

- changing playbooks
- changing gates
- making stop-doing items binding policy
- assigning an authoritative YDS rating
- merging, pushing, or promoting work

## YDS Boundary

YDS / Yosemite Decimal System ratings are human-authoritative only.

KaizenReview leaves `human_yds_rating` as `null` and may only emit a prompt for
the operator to rate the artifact. AI quality scores, including ForgeScore, are
advisory and must not be treated as authoritative YDS.
