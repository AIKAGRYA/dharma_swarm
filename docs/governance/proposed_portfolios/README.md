# Proposed Portfolios

This directory holds draft portfolio shapes. These files are **not authority**.
`docs/governance/ACTIVE_TRACK.yaml` remains the only live active-track owner.

Use this directory when the operator wants a future portfolio state designed
before the repo is clean enough to promote it. A proposal here may reference
tracks, closures, renames, and renderer work, but it does not open or close any
track until a later commit changes `ACTIVE_TRACK.yaml`.

Rules:

- Keep portfolio proposals evidence-linked and explicit about promotion gates.
- Treat clickable track pages as generated projections, not receipt authority.
- Prefer a flat phase model: at most five phases per track, at most three
  seams per phase, no recursive subtrack authority.
- Withdraw or refresh proposals that are older than 30 days before promotion.
