The packet exists to force that claim through evidence, gates, witness,
challenge, and feedback.

## Current Hard Truth

The strongest architecture is present in pieces:

- Dharma has typed metabolic objects: Outcome, ValueEvent, Contribution, VentureCell.
- Shakti feedback is partially wired through opportunity board feedback.
- MemoryKernel can label memory authority, but is read-only.
- Agora/SABP has live public membrane paths for submit, witness, challenge, canon, and compost.
- Darwin can shadow-ingest sealed packets through `apply_sealed_packet`.

The missing step is one artifact completing the full loop.

## Why This Is The Right First Integration Object

This packet is not assumed to be the final product or highest company form.
It is the smallest artifact that can test the whole organism at once.

If an organ cannot touch this packet, it is either:

1. not wired,
2. not needed for the first organism,
3. only a vision object,
4. or missing a small adapter.

That is the point.
