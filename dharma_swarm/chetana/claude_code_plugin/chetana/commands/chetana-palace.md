---
description: Render the memory palace — 10 pillar rooms + 5 system rooms as JSON Canvas.
---

Run `python -m dharma_swarm.chetana.cli palace` using the chetana venv.

Output is written to `~/.dharma/knowledge/memory_palace.canvas`. Open in Obsidian (with JSON Canvas support) or any tool that reads kepano's open Canvas spec to navigate atoms by pillar.

Pillar rooms: Levin, Kauffman, Jantsch, Deacon, Friston, Hofstadter, Aurobindo, Dada Bhagwan, Varela, Beer.
System rooms: Telos (Jagat Kalyan), R_V Research, Phoenix, Foundations, Operations.
