# F-016 — golden-frame capture script (s0-verifiers, deps: F-002)

## What it really requires
- `scripts/golden_capture.sh`: per size (80x24, 100x30, 120x40) boot one hermetic tmux session using the EXACT env recipe from boot_smoke.sh:29-31 (`COLORTERM=truecolor DHARMA_PYTHON=/nonexistent/python` + both `DHARMA_TERMINAL_*STATE_DIR` vars → mktemp), poll until "backend offline" renders (boot_smoke.sh:33-45 pattern), then walk every surface and `tmux capture-pane -p` each into `tests/golden/<size>/<surface>.txt`.
- The surface inventory, offline-hermetic, is exactly 12 static tabs — chat, mission, repo, commands, models, ontology, runtime, sessions, approvals, control, agents, evolution (mockContent.ts:7-118) — plus 2 overlays: modelPicker via ^P (app.tsx:2941-2952) and paneSwitcher via ^K (app.tsx:2954-2957). 14 surfaces × 3 sizes = 42 files; make the script COUNT against this inventory list so the verification ("file count matches") is mechanical.
- Navigate with plain Tab cycling (forward only) and poll for the target tab's title in the frame before capturing — frames need settle time. Close each overlay (Esc) before moving on.

## The non-obvious pitfall
Three traps: (1) dynamic tabs thinking/tools/timeline exist only after `tab.ensure` events (state.ts:174-180) — they never appear offline; don't list them in the inventory or the count check fails forever. (2) Shift-Tab is broken (navigates forward — DESIGN_FEEDBACK live finding #4) and printables `[ ] 1 2 3` are globally intercepted (LESSONS.md:19) — use forward Tab only. (3) Build in a `GOLDEN_OUT_DIR` override NOW: F-018's diff checker must capture into a temp dir, and without the override it will dirty tests/golden/ on every run.

## Fastest verification
Run the script twice back-to-back; `diff -r` the two output trees (must be empty); `find tests/golden -name '*.txt' | wc -l` = 42 (excluding pre-theme/); open 3 sampled frames and see real pane content. Bash interpreter, never zsh (claude-progress.txt:7-11). Temp cleanup via `find -mindepth 1 -delete; rmdir` — never the literal recursive-force-rm string (LESSONS.md:10).

## What NOT to do
Don't touch tests/golden/pre-theme/* (its git-diff-clean check is a standing per-commit gate). Don't capture SGR `-e` variants — text frames are the spec. Don't commit the captured corpus here — that's F-017's commit, this feature ships the script.
