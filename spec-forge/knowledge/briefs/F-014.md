# F-014 — Prettier + format:check (s0-hygiene, deps: F-013)

## What it really requires
- prettier is NOT installed (absent from terminal/node_modules and package.json:31-38). `bun add -d prettier` mutates the tracked terminal/bun.lock (tracked as-is since F-007, commit c750537e5); the frozen-install invariant (`bun install --frozen-lockfile` exit 0) must stay green after the add. Network installs work in this env (F-013 just installed eslint 10).
- Add `"format:check": "prettier --check ."` beside lint (package.json:15) plus a `.prettierrc` and `.prettierignore`, then one `prettier --write` pass so the whole tree passes.
- Existing src style: double quotes, semicolons, NO bracket spacing (`import {Box, Text} from "ink"` — TabBar.tsx:1-2). Prettier defaults (bracketSpacing:true, printWidth 80) rewrite every import and split long lines. Configure to match: `"bracketSpacing": false`, printWidth ≥120, then iterate until the diff is minimal.

## The non-obvious pitfall
Ratchet coupling. protocol.ts is exactly 4064 lines = the max_file_lines baseline (ratchet_baselines.txt); any net line growth from prettier line-splitting is an instant red (ratchet.sh:82-84). Worse: record_unknown=97 is a grep -c LINE count while true occurrences are 101 (claude-progress.txt:104) — several protocol.ts lines carry 2+ `Record<string, unknown>` occurrences, and a prettier split of one of those lines RAISES the line count past 97. Baselines may only move down (ratchet.sh:2-5); you cannot hand-raise them. Run `bash scripts/ratchet.sh` immediately after `prettier --write`, before anything else, and tune .prettierrc until all four counters are ≤ baseline.

## .prettierignore must cover
`LESSONS/` (append-only file; reformatting historic lines can re-trip fourfold-shakti-warrant via diff context — LESSONS.md:13, claude-progress.txt:52), `tests/golden/`, `assets/`, `node_modules/`, `bun.lock`. eslint already excludes scripts/ and LESSONS/ (eslint.config.js:24-29) — mirror that judgment.

## Fastest verification
`bun run format:check` exit 0 → mis-format one file → exit 1 → restore via `git show HEAD:<path> > <path>` (`git checkout --` is sandbox-blocked, claude-progress.txt:90) → exit 0 again. Then the standing gates: typecheck, bun test 527/0, `bash scripts/ratchet.sh`, boot_smoke.sh, pre-theme golden diff clean.

## What NOT to do
Don't reformat anything outside terminal/. Don't let prettier touch LESSONS/, goldens, or bun.lock. Don't regenerate the lockfile beyond the single prettier add. Don't raise any ratchet baseline to make a reformat fit — shrink the reformat instead.
