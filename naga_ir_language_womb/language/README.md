# Language Womb

The universal coding language seed, bootstrap receipt, grammar, typechecker, evaluator, and examples incubate here before graduation.

Highest goal: make epistemic modality and authority part of programming
language semantics. If a model answer is only `Attested_by`, the future
typechecker must prevent it from flowing into a `Proven_by` requirement.

Read `prior_art.md` before changing the grammar. New constructs must be
justified against existing LM programming frameworks, proof assistants,
type/effect systems, provenance systems, and probabilistic/paraconsistent
languages.
